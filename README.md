# Dualsens-edge-fix
Simple bash script that fixes for the Dualsens Edge controller binding under the Linux ecosystem. Used the https://github.com/ValveSoftware/steam-devices as a baseline for this.

Note that this is SPECIFICALLY for the Edge and not the stock Dualsens.

The edge by default mirror some face buttons and refuse to work with the touchpad without this fix. It also get recognized as a normal Dualsens so you cannot bind the extra buttons on steam input as well.
Make sure you disable the touchpad on this device via your DE or WM after running the script.
